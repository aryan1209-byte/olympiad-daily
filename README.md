# Olympiad Daily

Free daily practice questions for SOF IMO, NSO and school exams.

## Files
- `index.html`: the main site (questions are in the `questions` list in the script)
- `privacy.html`: privacy page
- `404.html`: shown for broken links
- `robots.txt`, `sitemap.xml`: help Google find the site

## Live site
https://aryan1209-byte.github.io/olympiad-daily/

Settings (form link, contact email) are at the top of the `<script>` in `index.html`.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public** repository named exactly `olympiad-daily`
2. Click **Add file → Upload files** and drag in all the files from this folder, then click **Commit changes**
3. Go to **Settings → Pages**, and under "Build and deployment" choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then click **Save**
4. Wait 1–2 minutes. The site will be live at `https://aryan1209-byte.github.io/olympiad-daily/`

## Updating the site
Edit a file on GitHub (pencil icon) or upload a new version. Changes go live in about a minute.
